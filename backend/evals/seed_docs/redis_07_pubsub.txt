# Redis 发布订阅（Pub/Sub）

Redis Pub/Sub 是消息通信模式。

## 模型
- 发布者（Publisher）将消息发送到频道（Channel）。
- 订阅者（Subscriber）订阅感兴趣的频道。
- 消息是即时推送的，不持久化。

## 命令
- PUBLISH channel message：发布消息。
- SUBSCRIBE channel：订阅频道。
- PSUBSCRIBE pattern：按模式订阅。

## 局限性
- 消息不持久化：订阅者离线时丢失消息。
- 没有 ACK 机制：不保证消息送达。
- 需要持久化和可靠投递时应使用 Stream。
