# 第1章 架构总览

MySQL 的架构分为三层：连接层、服务层、存储引擎层。连接层负责客户端连接管理、认证、权限校验。服务层包含连接器、查询缓存、分析器、优化器、执行器。存储引擎层负责数据的存储和读取，插件式架构支持多种存储引擎。
