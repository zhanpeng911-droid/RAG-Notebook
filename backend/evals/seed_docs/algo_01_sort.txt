# 排序算法

## 常见排序算法

| 算法 | 时间复杂度(平均) | 空间复杂度 | 稳定性 |
|------|-----------------|-----------|--------|
| 冒泡排序 | O(n²) | O(1) | 稳定 |
| 选择排序 | O(n²) | O(1) | 不稳定 |
| 插入排序 | O(n²) | O(1) | 稳定 |
| 快速排序 | O(n log n) | O(log n) | 不稳定 |
| 归并排序 | O(n log n) | O(n) | 稳定 |
| 堆排序 | O(n log n) | O(1) | 不稳定 |

## 稳定性
稳定性指相等元素排序后保持原有相对顺序。稳定排序在多关键字排序中有用。

## 快速排序原理
1. 选择基准（pivot）。
2. 将小于基准的放左边，大于的放右边。
3. 递归排序左右两部分。
