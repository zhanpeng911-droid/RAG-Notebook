# Go defer（延迟执行）

defer 语句在函数返回前执行，常用于资源释放。

## 执行顺序
多个 defer 按 LIFO（后进先出）顺序执行。

## 常见用途
```go
// 文件关闭
f, err := os.Open("file")
defer f.Close()

// 锁释放
mu.Lock()
defer mu.Unlock()
```

## 参数立即求值
defer 的参数在声明时求值，不是在执行时：
```go
i := 1
defer fmt.Println(i) // 输出 1
i = 2
```

## 性能
Go 1.14+ 大幅优化了 defer 的性能，几乎零开销。
