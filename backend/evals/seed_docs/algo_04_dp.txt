# 动态规划（Dynamic Programming）

动态规划将问题分解为子问题，存储子问题的解避免重复计算。

## 核心要素
1. 最优子结构：问题的最优解包含子问题的最优解。
2. 重叠子问题：子问题会被重复计算。

## 实现方式
1. 自顶向下 + 记忆化：递归 + 缓存。
2. 自底向上：迭代填表。

## 经典问题
- 斐波那契数列：dp[i] = dp[i-1] + dp[i-2]。
- 最长公共子序列（LCS）。
- 0-1 背包问题。
- 编辑距离。
- 爬楼梯：dp[i] = dp[i-1] + dp[i-2]。

## 状态转移方程
描述如何从子问题的解推导当前问题的解，是 DP 的核心。
