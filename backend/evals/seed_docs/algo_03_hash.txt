# 哈希表（Hash Table）

哈希表通过哈希函数将 key 映射到数组下标，实现 O(1) 平均查找。

## 哈希冲突解决
1. 链地址法（拉链法）：冲突位置用链表存储。Java HashMap 用此方法。
2. 开放地址法：冲突后找下一个空位（线性探测、二次探测、双重哈希）。

## 扩容
- 负载因子 = 元素数 / 数组长度。
- 超过阈值（如 0.75）时扩容（通常翻倍），重新哈希。
- 扩容是 O(n) 操作，但均摊到每次插入是 O(1)。

## 一致性哈希
- 用于分布式缓存（如 Redis 集群分片）。
- 节点增减时只影响相邻区间的数据，最小化缓存失效。
- 使用虚拟节点解决数据倾斜问题。
